# הקריקטורה שלי

צ׳אט בעברית ששואל את התלמיד 5 שאלות, מבקש סלפי, ושולח את הכול למודל התמונות של OpenAI כדי לצייר קריקטורה אישית.

- `public/index.html`: הצ׳אט שהתלמידים רואים
- `api/caricature.js`: השרת הקטן ששומר את מפתח OpenAI ופונה אליו

## העלאה לאוויר (פעם אחת, בערך 10 דקות)

### 1. מפתח OpenAI
1. נכנסים ל-https://platform.openai.com ומתחברים.
2. ב-**Settings → Billing** מוסיפים אמצעי תשלום ומטעינים קרדיט (5$ מספיקים להרבה תלמידים).
3. ב-**Settings → Organization → General** מאמתים את הארגון (Verify Organization). בלי האימות הזה OpenAI לא מאפשרת להשתמש במודל התמונות.
4. ב-**API keys** יוצרים מפתח חדש ומעתיקים אותו (הוא מתחיל ב-`sk-`).

### 2. Vercel
1. נכנסים ל-https://vercel.com עם חשבון GitHub.
2. **Add New → Project**, ובוחרים את הריפו `sticker-portfolio`.
3. ב-**Root Directory** לוחצים Edit ובוחרים את התיקייה `caricature-chat`.
4. פותחים את **Environment Variables** ומוסיפים:
   | Name | Value |
   |---|---|
   | `OPENAI_API_KEY` | המפתח מסעיף 1 |
   | `CLASS_CODE` | קוד שתבחרו, למשל `kita2026` |
5. לוחצים **Deploy**.

### 3. שליחה לתלמידים
הקישור לתלמידים הוא כתובת האתר עם הקוד בסוף:

```
https://<שם-הפרויקט>.vercel.app/?code=kita2026
```

מי שנכנס בלי הקוד הנכון יכול לענות על השאלות, אבל לא יקבל ציור. ככה אנשים זרים לא יכולים לבזבז לכם את הקרדיט.

## עלות
כל קריקטורה עולה בערך 5 עד 7 סנט (באיכות `medium`). אם לוחצים על "ציור נוסף", זו קריקטורה חדשה בתשלום.

## הגדרות נוספות (לא חובה)
| Name | מה זה עושה |
|---|---|
| `IMAGE_QUALITY` | `low` (זול ומהיר), `medium` (ברירת המחדל), `high` (יפה יותר ויקר יותר) |
| `OPENAI_IMAGE_MODEL` | מודל התמונות. ברירת המחדל: `gpt-image-1` |

אחרי שמשנים משתנה ב-Vercel, צריך לעשות Redeploy כדי שהשינוי ייכנס לתוקף.
